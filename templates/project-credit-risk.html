Business Interpretation

PD is only one part of credit risk

A borrower can have a relatively low probability of default but still create a meaningful expected loss when exposure or loss severity is large. This project separates the PD model from LGD and EAD assumptions and combines them only when calculating Expected Loss.

This project uses a deterministic synthetic credit dataset so it can run locally without storing real borrower information. It demonstrates modelling and validation workflow, not a production lending decision.
